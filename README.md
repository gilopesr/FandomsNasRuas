# FandomsNasRuas

Mobilização digital e urbana dos fandoms do Brasil a favor de Lula no segundo turno.

## 🤝SUA CONTRIBUIÇÃO É BEM VINDA
Apenas dei inicio ao projeto para facilitar o encontro das manifestações
Toda ajuda é bem-vinda para fortalecer essa mobilização! Seja no código, no design, na curadoria de conteúdo ou divulgando o projeto:

- Faça um Fork do projeto.
- Crie uma branch para sua alteração (git checkout -b feature/minha-contribuicao).
- Faça o commit (git commit -m 'Adiciona funcionalidade X').
- Faça o push para a branch (git push origin feature/minha-contribuicao).
- Abra um Pull Request.
